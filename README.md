# MiniSklad

Веб-приложение для учёта складских товаров. Поддерживает авторизацию, роли пользователей, добавление товаров, приход, расход и историю операций. Данные хранятся в SQLite.

## 1. Подготовка перед запуском

**Требования:** Windows и Python 3.12.

1. Откройте терминал в папке проекта.
2. Создайте виртуальное окружение:

   ```bash
   py -3.12 -m venv .venv
   .venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте аккаунт директора:

   ```bash
   py app.py create-director
   ```

5. Запустите приложение:

   ```bash
   py app.py
   ```

6. Откройте в браузере http://127.0.0.1:5000.

## 2. Тестовые пользователи



**Важно:** аккаунты кладовщика и менеджера необходимо предварительно создать через API будучи директором. Зарегестрироваться Директором, нажать на F12 и перейти в консоль и на полях username и password вставить свои значения

Для кладовщика:

fetch("/api/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    username: "storekeeper1",
    password: "Store123!",
    role: "storekeeper"
  })
}).then(r => r.json()).then(console.log);

Для менеджера аналогично:

fetch("/api/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    username: "manager1",
    password: "Manager123!",
    role: "manager"
  })
}).then(r => r.json()).then(console.log);


- **Директор:** управление товарами и пользователями, приход и расход.
- **Кладовщик:** оформление прихода и расхода, просмотр данных.
- **Менеджер:** просмотр товаров и истории операций.

## 3. Итоги

Добавлены авторизация, разграничение прав пользователей, управление товарами, оформление прихода и расхода, просмотр истории операций и хранение данных в SQLite.

Для реализации выбраны Flask и SQLite, поскольку они позволяют создать лёгкое приложение, которое просто запустить на обычном компьютере без отдельного сервера базы данных. Интерфейс реализован с использованием HTML, CSS и JavaScript.

Не успели добавить полноценное управление пользователями через интерфейс и удаление товаров.

Если бы был ещё один день, я бы в первую очередь реализовал удобную страницу управления пользователями, улучшил обработку ошибок и доработал отчёты по движению товаров.
